# Instrucciones para agentes

Antes de crear, diseñar o modificar la página, lee obligatoriamente `docs/kelodiamonds-mobile-audit/README.md` (y `data.json` para los estilos medidos). Es la referencia de cómo vamos a construir la página: estructura de secciones, colores, tipografías, botones, espaciados y comportamiento de cada elemento en móvil (384×856). No te apartes de ella sin aprobación de Kelffren.
