## Quality gates for each new page
1. Validate query intent using accessible sources; no fabricated keyword volumes.
2. Original explanatory answer near top; avoid copied descriptions and unsupported wear tests.
3. Manufacturer links for brand-specific verification; distinguish warnings from proof of authenticity. Never promise a definitive authenticity determination from a QR or photo.
4. Distinct title, description, H1, canonical, hreflang, breadcrumbs, and crawlable links to pillar, related pages, relevant real products and store.
5. Update the generator, sitemap and navigation together; preserve GitHub Pages base path `/perfume-bronx/`.
6. Run `python3 scripts/build-organic.py`, `python3 scripts/check-organic.py`, and `node scripts/test-organic.cjs`, plus existing project checks; inspect diffs for unrelated changes.
7. Verify published URL and actual GitHub Pages deployment; do not confuse deployment with Google indexing.
